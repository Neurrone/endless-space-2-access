One line per helper, with the file whose doc comment carries the real contract. This file is
loaded per-need (the index in `docs/dev-loop.md` points here) — it is NOT part of the
mandatory stage read. A NEW HELPER lands here (one row) and in its own doc comment, never in
`dev-loop.md`.
