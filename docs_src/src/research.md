# Research

The game draws technologies as dots on a wheel: four quadrants, each with five stages running outward from the centre, plus the victory ring. The mod exposes the wheel as a tree: quadrant, then stage, then the technologies of that stage in the order they are drawn.

Technologies can only be researched once their stage has been unlocked. Unlocking a stage is done by researching a certain number of technologies from the previous stage.

Otherwise, technologies can generally be researched in any order.

The mod reads relationships between technologies, such as cost reductions or a technology being mutually exclusive with another.
