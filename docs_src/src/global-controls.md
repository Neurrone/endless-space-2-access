# Global Controls

These controls are always in the tab order in every screen as the game always draws them. The mod announces hotkeys to move focus or activate these controls when available.

## Empire HUD

Use the arrow keys to move through the panel. This panel has several rows.

- Buttons to the 8 major screens
- Information about key resources
- Information on strategic resources
- The active research
- Controls to activate faction-specific abilities

## Tutorial

If enabled, this tab stop contains a control to expand the current tutorial popup

## Pinned Quest

This is the quest you're actively tracking

## Notifications and Turn Log

This is a list of notifications. `Ctrl+L` moves to the location of that notification. `\` dismisses the notification

## End turn controls

This contains the end turn and apply fleet movements button, which have dedicated shortcuts to activate them.
